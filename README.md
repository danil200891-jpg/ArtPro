# ArtProduction

Адаптивный статический сайт на React, TypeScript, Vite и Lucide. Основной язык — испанский; доступны русский и английский.

## Локальный запуск

Требуется Node.js 20.19+ или 22.12+ и npm.

```sh
npm install
npm run dev
```

Откройте адрес из вывода Vite (обычно http://localhost:5173).

В этой среде зависимости установлены через встроенный pnpm. При отсутствии npm можно запускать напрямую:

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
```

## Редактирование

- `src/services.ts`: контакты, идентификаторы услуг, цены и категории.
- `src/translations.ts`: основные переводы ES/RU/EN.
- `src/config.ts`: общая конфигурация и подписи языка/города.
- `src/presentation.ts`: заголовок услуг, основной CTA и пояснение об индивидуальном расчёте стоимости.
- `src/main.tsx`: структура страницы, иконки и взаимодействия.
- `src/styles.css`: переменные палитры, оформление, адаптация и анимации.
- `index.html`: начальные SEO и Open Graph метаданные. При переключении языка title и описания обновляются.
- `public/`: favicon и графика Open Graph. Перед публикацией рекомендуется заменить SVG Open Graph на PNG 1200×630 и указать абсолютный публичный URL в og:image; URL сайта пока не задан.

Шрифт Manrope загружается из Google Fonts, при отсутствии подключения используется Arial. Остальной интерфейс не требует внешних API. Цены указаны без IVA; примечание +21% отображается под услугами.

## Ссылки для рассылок

- `/?from=whatsapp` — основной контакт Instagram.
- `/?from=instagram` — основной контакт WhatsApp.
- `/?service=reels` — выделить услугу и прокрутить к ней.
- `/?from=instagram&service=corporate` — совместное использование параметров.

Идентификаторы: `reels`, `corporate`, `events`, `content`, `photography`, `smm`, `ads`. Неизвестные значения игнорируются. WhatsApp получает сообщение на выбранном языке; при выборе услуги сообщение содержит её название. Обе контактные кнопки есть в завершающем блоке. Язык сохраняется в localStorage, при запрете хранилища сайт продолжает работать.

## Production

```sh
npm run build
npm run preview
```

Команда build сначала проверяет TypeScript, затем создаёт `dist/`. Настройка `base: '/ArtPro/'` обеспечивает работу ресурсов в подкаталоге GitHub Pages. Локальный адрес Vite: http://localhost:5173/ArtPro/ (порт может отличаться).

## Автоматическая публикация на GitHub Pages

Сайт: https://danil200891-jpg.github.io/ArtPro/

Workflow `.github/workflows/deploy.yml` запускается при отправке изменений в `main`, а также вручную из GitHub → Actions. Он использует Node.js LTS, устанавливает зависимости через `npm ci`, выполняет `npm run build` и публикует содержимое `dist` официальными GitHub Pages Actions. В Settings → Pages выбран источник GitHub Actions.

Для обновления сайта внесите изменения и отправьте коммит в `main`. Ход сборки и публикации доступен во вкладке Actions репозитория. Файлы `dist` не нужно коммитить. Для CI используется `package-lock.json`; при изменении зависимостей обновляйте его через npm install.

Сервер, база данных, платные API и формы с передачей данных не используются. Контакты открываются в новой вкладке; отправку сообщения посетитель подтверждает самостоятельно.


## Логотип и раздел «О нас»

- `src/about.ts` — полный текст раздела на русском, испанском и английском.
- `public/artproduction-original.png` — оригинал предоставленного логотипа.
- `public/artproduction-logo.webp` — версия без потерь с удалёнными прозрачными полями; рисунок, цвета и пропорции сохранены.
- `public/favicon.png` — уменьшенная версия полного оригинального логотипа.

Логотип отображается без обрезки, фильтров и деформации. Размер в шапке задаётся через `.brand-logo` в `src/styles.css`: 100 px на десктопе и 82 px на мобильных экранах, высота рассчитывается автоматически.


## Минималистичная версия

Порядок разделов: главный экран → о нас → услуги и цены → контакты. На главном экране одна кнопка перехода к контактам. WhatsApp и Instagram размещены в контактном блоке; при `from=whatsapp` Instagram идёт первым. Все семь услуг показаны сразу, без фильтров и повторяющихся контактных кнопок. Параметр `service` выделяет услугу и добавляет её в запрос WhatsApp.

Актуальные условия: съёмка мероприятий — от 400 € за 3 часа; таргетированная реклама — от 400 € в месяц за настройку и ведение, рекламный бюджет отдельно. Остальные цены сохранены. Общее пояснение об индивидуальном расчёте и IVA выводится один раз после услуг.

## Визуальные карточки услуг

`src/visuals.css` задаёт сетку отдельных карточек, тематические SVG-иконки Lucide, рамки, оформление цен, эффекты наведения и фоновые красные свечения. На десктопе используется сетка до трёх колонок, на планшетах — две, на телефонах — одна. Тексты и цены по-прежнему берутся из конфигурации. Декоративная анимация выполняется один раз; prefers-reduced-motion отключает движение.
